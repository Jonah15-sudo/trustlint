# TrustLint TLS Security Review

## Service Overview

**TrustLint TLS Security Review** helps SaaS teams identify TLS certificate, trust-chain, and configuration risks before they become incidents.

## Scope

Authorized public endpoints only. We assess:

- Certificate validity and expiration
- Trust chain integrity (root CA, intermediates, completeness)
- TLS protocol version (deprecated TLS 1.0/1.1 detection)
- Cipher suite strength
- OCSP revocation evidence where available
- Hostname matching

## Delivery

Written report within 48–72 hours of authorized scan completion.

## Pricing

**Introductory price:** $149 flat fee for up to 10 authorized endpoints.

## Deliverables

- Executive summary
- Prioritized findings by severity (critical / high / medium / informational)
- Evidence for each finding
- Remediation guidance
- Short review call (15 minutes)

## Exclusions

- No exploitation or intrusion testing
- No compliance certification (SOC 2, PCI DSS, HIPAA, etc.)
- No guarantee of security
- No production ALLOW/DENY claims
- Assessment is point-in-time screening only
